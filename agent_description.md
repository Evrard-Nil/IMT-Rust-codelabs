### Agent Name: IMT Rust Codelabs

This agent is a collection of self-contained Rust programming exercises designed to teach fundamental concepts of the Rust language. Each "lab" focuses on a specific topic, providing practical code examples to illustrate core features and best practices.

### Key Features:

*   **Ownership and Borrowing:** Demonstrates Rust's unique memory management model, including mutable and immutable references, and how to avoid common pitfalls like data races.
*   **String Manipulation:** Provides examples of creating, modifying, and slicing strings using various Rust string types.
*   **Structs:** Covers the definition and instantiation of different types of structs (classic, tuple, and unit structs), along with implementing methods for custom logic.
*   **Enums:** Illustrates the use of enums for defining distinct message types and processing them using `match` expressions.
*   **Concurrency:** Includes an example of basic concurrent programming using threads and atomic operations to manage shared state.
*   **Data Structures:** Demonstrates the use of `Vec` (vectors) for dynamic arrays.

### Inputs:

None. The exercises are self-contained code examples and do not accept external input at runtime.

### Outputs:

Console output (via `println!`) for demonstrating program behavior and test results for verifying the correct implementation of the exercises.
